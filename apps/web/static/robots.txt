# Worth stating, because Disallow is the wrong reflex here: it stops the crawl,

# can still be listed with no way to get it removed. It also blocks the
# unfurlers — facebookexternalhit, Twitterbot, LinkedInBot and Slack all honour
# robots.txt — which would switch off link previews on the platforms most likely
# to carry a shared calculator link.
