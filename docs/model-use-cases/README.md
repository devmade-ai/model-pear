# Model Use Cases

> **Purpose**: Realistic scenarios where each transaction model variant is the best choice
> **Total Coverage**: 6 models, 47 variants

---

## Overview

This folder documents **when to use each variant** of the 6 transaction models. Each file explains:

- What makes that variant unique
- Real-world scenarios where it's the best choice
- Why it's better than alternatives in that scenario
- Transfer pricing considerations

## Quick Model Selection

| If the priority is... | Use Model |
|----------------------|-----------|
| Buyer owns IP outright | **1** (Development Services) |
| Developer keeps IP, licenses to many | **2** (Licence) |
| Shared ownership, no interco profit | **3** (Joint Development) |
| Prove it works before transfer | **4** (BOT) |
| Clean one-time sale | **5** (Sale) |
| Recurring revenue, low Buyer capex | **6** (SaaS) |

## How to Use This Documentation

1. **Start with the model** that fits your high-level goal (see table above)
2. **Read the variant summaries** in that model's file
3. **Match your scenario** to the variant descriptions
4. **Review TP considerations** if related parties are involved
